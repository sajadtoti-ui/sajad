# تطبيق «مقابلة»: نسخة Flutter 0.6

تحويل النموذج الأولي v0.6 إلى تطبيق Flutter، بنفس الشاشات والبيانات والقواعد.
البيانات حالياً تنحفظ على التلفون نفسه (للتجربة)، والخطوة الجاية ربطه بسيرفر Supabase.

## شنو موجود
- **شاشة البداية:** حركة اللوكو (الفقاعتين يتقاربن، وتنزل البنايات والأشخاص، وبعدها الاسم).
- **الدخول والتسجيل:** رقم الهاتف، ورمز تحقق (للتجربة: 1234)، وكلمة مرور، وقفل مؤقت بعد 5 محاولات.
- **الموظف:** صورة حية إلزامية، وصورة ملف يگدر يخفيها، والعنوان ويه خيار «أخرى»، و100 تخصص ويه «أخرى»، والشهادة الدراسية (إلزامية للهندسة والصحة والتعليم)، وهوية النقابة، والشهادات الإضافية، واللغات (إنكليزي وألماني)، و«عرّف بنفسك» يتحول لكلمات مفتاحية.
- **الامتحانات:** بنك أسئلة خاص لكل تخصص (10 تخصصات حالياً)، وأسئلة بالصور، و30 ثانية لكل سؤال، واختبار اللغة بعد امتحان المهنة.
- **التعلّم:** أسئلة الأسبوع، وكورس الشهر، والنقاط، وشارة «🔥 نشِط».
- **المجتمع:** نشر وتعليق وإبلاغ، ويحجب الأرقام والروابط تلقائياً.
- **الشركة:** تصوير البطاقة الوطنية (وجه وظهر)، وصورة حية، والبحث بالتخصص والجنس والخبرة والكلمة المفتاحية ووسيلة النقل واللغة والمنطقة والمسافة بالكيلومترات.
- **المقابلة:** طلب، ثم تحديد موعد، ثم مقابلة فيديو، ثم مقابلة حضورية، ثم توظيف. ويه محادثة تحجب الأرقام، والصورة والمستندات تظهر بعد القبول بس.
- **الموارد البشرية:** اعتماد الدرجات، وتوثيق الشركات والهويات والمستندات، واعتماد اللغات، والمناطق والتخصصات الجديدة، والبلاغات، والإحصائيات، وسجل العمليات.

## خطوات التشغيل على اللابتوب

1. **نصّب Flutter وAndroid Studio** من الموقع الرسمي: https://docs.flutter.dev/get-started/install
   وتأكد إن كلشي تمام بالأمر:
   ```
   flutter doctor
   ```
2. **فك ضغط المشروع**، وافتح الطرفية (Terminal) داخل مجلد `muqabala_flutter`.
3. **ولّد ملفات أندرويد وiOS** (ما تمسح ملفاتنا):
   ```
   flutter create . --org iq.muqabala --project-name muqabala --platforms android,ios
   ```
4. **نزّل المكتبات وولّد الأيقونة:**
   ```
   flutter pub get
   dart run flutter_launcher_icons
   ```
5. **اسم التطبيق بالعربي:** افتح `android/app/src/main/AndroidManifest.xml` وغيّر
   `android:label="muqabala"` إلى `android:label="مقابلة"`.
6. **جرّبه على تلفونك:** شغّل «خيارات المطوّر» و«تصحيح USB» بالتلفون، واشبكه بالكيبل، وبعدها:
   ```
   flutter run
   ```
7. **اطلع ملف APK:**
   ```
   flutter build apk --release
   ```
   الملف يطلع هنا: `build/app/outputs/flutter-apk/app-release.apk`

### للآيفون (لاحقاً، يحتاج Mac)
أضف هذي السطور داخل `ios/Runner/Info.plist`:
```xml
<key>NSCameraUsageDescription</key>
<string>نحتاج الكاميرا حتى تاخذ صورة حية للتحقق من هويتك وتصوّر مستمسكاتك</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>نحتاج الصور حتى ترفع صورتك وشهاداتك</string>
```

## ترتيب الملفات
```
lib/
  main.dart              ← بداية التطبيق والشريط العلوي
  data/
    constants.dart       ← التخصصات والمناطق وبنوك الأسئلة (مولّد من النموذج)
    logo.dart            ← طبقات اللوكو
    models.dart          ← نماذج البيانات
    store.dart           ← كل القواعد والبحث والحفظ
  widgets/common.dart    ← عناصر الواجهة المشتركة
  screens/
    splash.dart          ← حركة اللوكو
    auth.dart            ← الدخول والتسجيل
    register.dart        ← تسجيل الموظف وتعديل معلوماته
    worker_home.dart     ← صفحة الموظف والتعلّم والمجتمع والـCV
    exam.dart            ← الامتحانات
    company.dart         ← الشركة والبحث
    interview.dart       ← مراحل المقابلة والمحادثة
    hr.dart              ← لوحة الموارد البشرية
```

## الخطوة الجاية
ربط `store.dart` بسيرفر Supabase، وتسجيل دخول حقيقي برسائل واتساب، وتخزين الملفات بمكان مقفول.
الشاشات ما تحتاج تتغير هواية، لأن كل المنطق بملف واحد.
